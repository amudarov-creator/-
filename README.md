# CS2 Analytics Bot

Запускаемый MVP Telegram-бота аналитики CS2. Он не скрейпит HLTV и не генерирует фиктивные статистические данные. Ввод поступает только из лицензированного источника (включён каркас PandaScore) и сохраняется в PostgreSQL с идентификатором источника.

## Быстрый запуск

1. Установите Docker Desktop и создайте `.env` из `.env.example`.
2. Заполните как минимум `TELEGRAM_BOT_TOKEN`; `PANDASCORE_TOKEN` нужен только для импорта лицензированных данных.
3. В каталоге проекта выполните:

```bash
docker compose up -d postgres redis
docker compose run --rm bot alembic upgrade head
docker compose up -d bot
```

4. Для разового безопасного импорта: `docker compose run --rm worker`.

Без токена PandaScore worker завершится без ошибки и не создаст выдуманных записей. Для тестов локально: `pip install -e '.[dev]'` и `pytest`.

## Что работает сейчас

- `/start` и inline-меню;
- поиск игроков, уже загруженных в БД;
- `/player <id>`: отчёт за 12 месяцев по сохранённым картам, K/D, ADR, rating/KAST/impact, форма и стабильность;
- админский `/health` по Telegram ID из конфигурации;
- чистые тестируемые формулы и PostgreSQL миграция;
- авторизованный PandaScore-клиент и идемпотентный импорт команд.

## Известные ограничения

Полноценная нормализация matches/maps/player stats, сравнение команд, графики, кеш Redis, фоновые очереди, экспорт, подписки и все round/event функции пока **не реализованы**. Они не представлены как готовые кнопки: меню сообщает об ограничении. Это сделано, чтобы не вводить пользователя в заблуждение до получения контрактного образца API и определения доступных полей. См. [DATA_SOURCES.md](DATA_SOURCES.md) и [ARCHITECTURE.md](ARCHITECTURE.md).
